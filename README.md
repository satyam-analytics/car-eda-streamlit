# 🚗 Car EDA Project – Streamlit Dashboard

### 🚀 Live Demo 
**[https://my-car-analysis-app.onrender.com/]**

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a car dataset and presents
insights through an **interactive Streamlit web dashboard**.

The dashboard helps users understand how different factors affect car prices and features.

---

## 🧠 Key Analysis Includes

* Car price distribution
* Fuel type analysis
* Transmission (Manual vs Automatic)
* Mileage, engine & power analysis
* Ownership & car age impact
* Interactive filters for better insights

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Streamlit

---

## 📂 Dataset

* `Cars.csv` – Raw dataset
* `Cars_cleaned.csv` – Cleaned dataset used for analysis

---

## 🚀 How to Run This Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
